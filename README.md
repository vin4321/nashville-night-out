# Nashville Night Out

A phone-friendly guide for a group trip to Nashville: lunch, things to do, dinner and drinks, each with
Google and Tripadvisor ratings, a transparent 0–100 score, walking/driving times and what's nearby next.

**Open it:** https://vin4321.github.io/nashville-night-out/

`index.html` is a single self-contained page (no build step, no tracking). It works without JavaScript,
and adds a search box when JavaScript is available.
